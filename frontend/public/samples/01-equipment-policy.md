# EQ-17: Shared equipment checkout

FICTIONAL DEMONSTRATION DOCUMENT. Not actual agency policy.

Issued: January 1, 2026. Owner: Operations desk.

## Standard return period

Employees must return shared equipment within five working days of checkout.
The operations desk records checkout and return dates in the equipment register.

## Extensions

The operations desk may approve an extension before the original return date.
Employees must record the new return date in the equipment register. This policy
does not specify a fee for late returns.
